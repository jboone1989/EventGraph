## Search Before Build / 实证

已使用连接的 Cloudflare GraphQL API 读取 `livingruntime.com` 和 `www.livingruntime.com` 的 `rumPageloadEventsAdaptiveGroups`。2026-11-04 07:32 至 11-11 07:32 UTC：总计 **1775 次 RUM 页面加载**，按页面类型为：新闻详情 **501**、知识实体详情 **422**、探索页 **341**、事件详情 **110**、首页 **70**、/all **46**、日报/周报详情 **12**，后台另有 **217**。最近 24 小时总计 141 次 RUM 页面加载、32 visits：新闻详情 26、首页 27、/all 19、事件详情 15、探索页 5。

HTTP 请求量不能等同可变现真实读者：过去 24 小时 /explore、/en/explore 的数千请求主要由 ElevenlabsCrawler（美国产生的两条主要记录合计 **5582**）、Semrush/MJ12/Amzn-SearchBot 等自动爬虫产生。RUM 页面加载本身也不能保证真人；7 天实体/探索/新闻在某几天有集中异常增量，应剔除自动浏览后再估算广告收益，不允许把 422 次实体 RUM 当成 422 个真实用户。

`apps/web/app/routes/item.tsx` 已有 `briefText`、`reasonText`、`ItemExplainer`、`EventContext`、知识实体关联及原始来源链接，应该复用现有可读内容和人工编辑能力，而不是为广告单独生成 LLM 文案。

Google 官方政策：https://support.google.com/publisherpolicies/answer/11112688；Auto ads 控制：https://support.google.com/adsense/answer/9305577。广告资格独立于新闻 SEO 索引。不能把自动生成/自动精选误认作人工审看或策展。

## US1 / 广告候选优先级（仅作获批后的方案，不启用真实广告）

1. **首要变现候选：新闻详情 `/items/:id`、`/en/items/:id`**。页面仅在有真正发布的有效内容、可追溯原始信源、实质独立增量（背景、真实来源比较、影响解释或有证据的事件关联）及可核验的人工编辑审看/策展证据时具备候选资格。不能由 `indexable`、`selected`、`seo_indexed_at`、LLM 评分或自动摘要成功推导已人工审核。只有短 AI 摘要、复写转载、标题+原文链接、模板推荐语、无有效英文内容的英文路由禁投。优先复用现有后台人工编辑/策展痕迹，**不要求所有新闻逐篇人工审批作为 SEO 收录前置**，也不假称自动流程具备人工审看。缺乏可验证证据应明确标记 UNVERIFIED，不得默认投放。
2. **首页 `/` 与 `/en`：有条件的第二候选。** 必须已有实质可阅读的编辑内容和策展证据；仅新闻链接/导航卡片、空模块、滚动列表时一律不投。若当前首页不足够，文档写“首页暂不具备资格”，不得为广告凭空填充 AI 文章。
3. **第二批：事件详情**有多来源证据、实质背景与真实策展时可投；研究/完整日报详情仅作为流量很小的补充。实体详情（过去 7 天 422 RUM）列入内容质量与自动化浏览观察，不直接准入。
4. **暂时禁投**：`/explore`、`/en/explore`（爬虫请求极高，但 RUM 最近 24h 仅 5 次）、`/all`、`/hot`、`/knowledge` 列表、搜索结果、各类列表页、政策与“更多”页、管理/登录页、空白/正在加载/纯链接/草稿/撤回、404/500/503、API 失败、任何未验证合格的正文页。
5. **固定广告位置（获批后）**：合格新闻每篇最多 1 个手动广告位，放在已经真实展示的 AI 导读、独立价值解释 / 实质事件背景**之后**、后续新闻/可合法展示的完整正文之前；如果内容不足形成实质阅读段落则本页 0 广告。远离“阅读原始报道”按钮、卡片和实体导航等控件，清楚标记“广告 / Advertisement”，手机 390px 与桌面不误触、遮挡。合格首页最多 1 处，仅能放在足够长的实际编辑内容之后，**不得夹在纯导航/新闻卡片之间**。事件、研究和日报保留旧规格的有限固定位置。

## US2 / 申请前安全与两条任务并行约束

6. **本次不插入或启动任何真实广告**：保留已有 AdSense 所有权验证 meta/ads.txt，不新增 `adsbygoogle.js`、Auto ads、真实广告单元、广告请求、追踪、外部 API 或空占位。申请阶段全站所有页面（新闻、首页、探索、404/5xx、空/错/加载、后台、中英、桌面/390px、SPA 转场）Google ad-serving JS 与请求必须都是 **0**。验证 meta 不属于 ad-serving JS。
7. 必须从已存在 `docs/adsense-readiness.md` 修正广告候选和优先级，并通过既有 `scripts/adsense-preflight.mjs` / `scripts/adsense-smoke.mjs` 或现成浏览器回归校验；不要新建后台配置、LLM 工作流、定时器、分析系统、广告组件或数据库字段。AdSense 后台 Auto ads / CDN/Tag Manager 是否启用无法由 GitHub 代码确定，需账户核验，未核查写 UNVERIFIED。后续实际投放另需 AdSense 通过、隐私/CMP 确认和用户明确授权。
8. **不能与 #564 重复修改**：#564 仍依旧版已批准 SHA 执行研究空态/申请前整改；本修订只在其现有工作基础上**增量修正广告候选与位置文档/断言**。实现者开工需核对 #564 的 GitHub Issue、Worker PR、当前 develop；若旧 PR 尚未合并，遵循现有原生串行 Agent 队列，不分叉实现同一文件；最终以当前 develop 为基线，不覆盖任何已经合并的空研究页/验证测试。
