# 每日模型调用统计：工作项

## Work Items

### T001 — 复用回执明细的 UTC 日模型尝试聚合
**Scope:** 在现有 admin runs 后端/合同/API 提供 7/30 天按 UTC 日总数与单日 provider+模型/实例统计；补充未来模型实例 ID 的既有回执摘要字段（若经代码核实必要）。明确试探与生产覆盖边界，不新增表或调度器。
**Depends on:** none
**Acceptance:**
- 同一日 2 成功、1 失败、1 unknown、1 pending → 总数 5、成功 2、失败 2、进行中 1、未知 1；趋势总数与同日日明细一致。
- 自动路由失败后换模型两次计入，复用回执不计新调用；非自动路由模型请求、Embedding 和 Graphiti 均计入，非模型外部服务不计入。
- UTC 边界、7/30 日限制、历史缺实例 ID 说明与新记录实例隔离有真实 SQL/单元或 API 测试；所有接口需要既有 admin 鉴权且不泄露密钥。

### T002 — 运行与积压页面呈现模型调用趋势及明细
**Scope:** 在已有运行与积压页复用后台 UI 展示当日指标、7/30 日趋势和单日模型明细；处理选择日期、空数据、API 失败、超长名称、移动端；不影响三队列和重试。
**Depends on:** T001
**Acceptance:**
- 默认 UTC 7 日含今日、可选 30 日，今日指示未结束；按日期选择时趋势、标题和分页明细同步变化；0 次与加载失败区分。
- 模型表有 provider、模型/可追踪实例、总次数、成功、失败、成功率，调用量降序；历史连接未区分状态显示明确；390px 可用且长模型名不挤压数值。
- 浏览器/API 验证不影响原三队列、失败行单条及批量重试；记录实际已跑验证，未验证的不报告 PASS。
