# 编辑运营能力（Editorial Ops）规格 v1.0（随 PR 提交，草案待批）

> **状态：Draft**，实现自 `specs/003-content-assets/spec.md` §6 Phase 2 清单（eb8705a）。使用者 2026-10-24 指示「按照 spec 开始开发」。本 PR 只做不需要外部凭据的三项（FR-001/002/003）；邮件订阅与公开频道推送（FR-004/005）在此立规格，实现另起分支。

## 1. 背景与目标

内容资产层（specs/003）上线后，运营动作还剩三个别扭点：

1. **编辑手记要随代码部署**——`site/editor-notes.ts` 改一次发一版，日常写作不可持续；
2. **没有「接下来会发生什么」的页面**——读者只能追已发生的事，BLS/Fed/ECB 的发布节奏是天然的回访理由；
3. **单来源快讯还占着独立事件页**——specs/003 标了「快讯」，但页面仍是薄页，浪费抓取预算。

目标：让编辑的日常动作（写手记、维护日历）不依赖发版；把「即将发生」做成可订阅（iCal）的入口；把快讯页收敛到条目页。

## 2. 用户可见行为

### 2.1 编辑手记后台编辑（FR-001）

- 后台「内容」组新增「编辑手记」页：按日期列出最近 60 天的日报；每天可编辑中文手记（必填）与英文手记（选填），保存后**两分钟内**对读者可见（日报页缓存与接口同为 120 秒），写进审计日志。
- 日报页（当日与往期）显示的手记改为读数据库；`site/editor-notes.ts` 降级为**种子数据**：部署种子把文件里已有日期插入库（`ON CONFLICT DO NOTHING`，不覆盖后台编辑），此后文件不再参与渲染。
- API：`GET /api/admin/notes?days=60`、`POST /api/admin/notes`（day/note/noteEn），仅管理员（沿用 sessionPrincipal + CSRF）。
- 日报读取层（`loadReport`）为 `kind=daily` 附带 `editorNote: { note, noteEn } | null`；非日报恒为 null。缓存与既有报告 ETag 一致。

### 2.2 政策与数据日历（FR-002）

- 新页面 `/calendar`（英文 `/en/calendar`）：**人工维护**的官方发布日程，按月分组列出未来条目（日期、机构徽标文字、事件名、可选原文链接）；过当日仍显示在「本月已过」小节，超过 60 天不显示。页面声明数据由编辑维护、以官方页面为准。
- `site/calendar.ts` 是唯一数据源（结构化数组：date/time/timeZone/source/title/titleEn/url）；首批录入 2026 年余下 FOMC 会议（1 月/3 月/4 月/6 月/7 月/9 月已过，只列 10-27/28、12-8/9）与 EIA 周度天然气/石油报告的节奏说明（每周三，规则条目不进列表、进说明区）。**BLS/ECB 具体日期由运营者核对官方页后补**，不凭记忆编造。
- 导出：`GET /calendar.ics`（api 服务，`text/calendar`，ETag + 公共缓存 1 小时），VEVENT 只含带确切日期的条目，UID 稳定（`calendar-<date>-<source>@site`）。
- `/calendar` 进 sitemap（数据哈希作 revision，日更）；电脑侧栏「更多」组加「日历」入口（中英 label），手机入口同研究栏目。

### 2.3 快讯页收敛（FR-003，取代 specs/003 FR-003 的页面表现）

- 判定沿用 specs/003：单来源且综述低于 `SEO.minSingleSourceDigestChars` 的事件为快讯（`story.note`）。
- 快讯事件页（`/story/:id`）**302 重定向**到它唯一报道的条目页（英文路径重定向到 `/en/items/:id`）。链接不断、可随时回退；这些页本就 `noindex` 且不进 sitemap，重定向不损失收录。
- specs/003 的「快讯」页面标记（Badge）随之移除；`StoryDetail.note` 保留（重定向判定用）。相关页面测试改为断言重定向。

### 2.4 日报邮件订阅（FR-004，本 PR 仅规格）

- 双确认订阅（邮件+token 确认）、一键退订、隐私页新增「邮件订阅」小节；发送走通用 SMTP 环境变量（`SMTP_HOST/PORT/USER/PASS/FROM`），**未配置时整块隐藏**（安全阀默认关）。每日日报生成后由 worker 发送纯文本+HTML。需运营者确认发送服务与退信处理后再实现。

### 2.5 公开频道推送（FR-005，本 PR 仅规格）

- 飞书群机器人 webhook（复用 FEISHU 告警通道的发送设施，独立 webhook 地址与开关）与 Telegram Bot（`TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID`）两个可选出口，按「当日精选」分发；默认关闭。需运营者提供群/机器人凭据后再实现。

## 4. 非目标

- 不做日历的自动抓取/解析（官方日程页结构不稳；先人工维护，密度可控）。
- 不做手记的富文本/图片（纯文本段落，与日报排印一致）。
- 不做快讯页 301（保留 302 的可逆性；这些页无收录价值，无需权重合并）。
- 不动 specs/003 已验收的收录/门禁规则。

## 5. 假设与依赖

- 迁移 `0112_editor_notes.sql` 只建一张引擎表（单语句、在线安全）。
- 日历数据正确性由运营者负责；首批只录 FOMC 两个会期（公开日程），其余机构日期留待核对后补。
- 手记表按 `day` 主键，与日报 key 同构（北京时间日期字符串）。
