# Feature Specification: 英文版版面与中文版对齐（english-layout-parity）

**Feature Branch**: `feature/english-layout-parity`

**Created**: 2026-10-22

**Status**: Draft（批准来源：使用者 2026-10-22 在开发会话中批准的对齐计划；合并前以本文件提交后的 commit SHA 为准）

**Input**: 使用者要求："英文的版面相对中文的来说也太素了，两者应该一致，只是语言不同而已。" 范围确认为全部英文页，并补齐缺失的英文周报/月报地址。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 英文读者看到与中文版相同的版面 (Priority: P1)

一位把界面切到英文（或访问 `/en/*` 地址）的读者，打开主题列表、主题详情、日报、文章页以及关于、更新日志、条款、隐私、反馈、收藏、Agent 接入、日报归档页时，看到的版面结构与中文版一致：同样的卡片样式、品牌标识、密度、栏目结构、移动端与桌面端布局；不同的只有文字语言。此前这些页面的英文版是丢弃了中文版排版的简化页。

**Why this priority**: 这是本需求的直接动机——英文版"太素"，读者拿到的是二等版面。

**Independent Test**: 逐页在中英两种语言下打开并对比结构：两侧的区块种类、层级与交互元素一致，仅文案不同。

**Acceptance Scenarios**:

1. **Given** 站点有主题数据，**When** 读者分别打开中文与英文主题列表页，**Then** 两侧均为"分组 + 主题卡"同一版面：品牌标、最新一条精选标题、近 30 天条数（或"暂无新精选"）、移动端列表/桌面端多列卡片的响应式行为完全一致，仅文字为各自语言。
2. **Given** 站点有一篇已生成英文摘要的报道，**When** 读者打开该报道的英文页，**Then** 版面与中文文章页一致（评分徽章、导读、正文工具、相关事件、收藏等同一结构），导读与"为何重要"显示英文内容。
3. **Given** 站点有一期日报，**When** 读者打开英文日报页，**Then** 版面与中文日报同一报纸结构（报头、头版、各版、快讯、前后期导航、版权栏）；英文侧的内容槽位用可得英文填充，只有中文的槽位留空但不改变版面结构。
4. **Given** 读者在关于/更新日志/条款/隐私/反馈/收藏/Agent/日报归档任一页切换语言，**Then** 页面结构不变，只有文字切换；反馈页在英文下仍保留截图上传与草稿等完整功能。

### User Story 2 - 英文周报与月报有固定地址 (Priority: P2)

英文读者和外部引用者可以通过 `/en/weekly`、`/en/weekly/<期号>`、`/en/monthly`、`/en/monthly/<期号>` 直接访问英文周报月报，与已有的 `/en/daily` 一致；语言切换按钮在周报月报页也能正确互跳；这些地址带正确的 hreflang 指向中文对应页。

**Why this priority**: 补齐英文版的结构缺口，但依赖 User Story 1 的版面合并才有内容可看。

**Independent Test**: 直接请求四个新地址，返回英文周报/月报页面；语言切换在两种语言间正确跳转。

**Acceptance Scenarios**:

1. **Given** 已发布周报与月报，**When** 读者访问 `/en/weekly/<key>`，**Then** 看到英文版面的该期周报；`/en/monthly` 同理。
2. **Given** 读者在 `/weekly/<key>` 点语言切换 EN，**When** 跳转完成，**Then** 地址变为 `/en/weekly/<key>`；反向切换同理。

### User Story 3 - 英文页永不把中文当英文展示 (Priority: P2)

英文页面（含 `/en/*` 地址与偏好切换两种途径）不得出现中文文本被当作英文内容展示：无英文摘要的报道在英文页按既定规则回退（原文标题可读时显示原文标题，否则显示占位说明），只有中文的报告导语、版面导读等槽位在英文页省略。这是站点既有铁律，本次改造不得引入违反它的槽位。

**Why this priority**: 是本次改造的正确性边界，违反即倒退。

**Independent Test**: 抽样渲染英文页面，断言正文文本节点不含汉字（存项标题等按回退规则处除外——回退处显示的是"打开原文"类占位，不是中文）。

**Acceptance Scenarios**:

1. **Given** 一篇只有中文标题与摘要的报道，**When** 读者打开其英文页，**Then** 标题位置显示回退占位或原文标题入口，不出现中文摘要冒充英文。
2. **Given** 一期报告的导语只有中文，**When** 读者打开该期英文报告页，**Then** 导语槽位省略，版面其余部分正常。

### User Story 4 - 退役英文文章页专用的事件上下文接口 (Priority: P3)

文章页版面合并后，英文文章页与中文页展示同样的"相关事件与后续追踪"结构，不再调用专用的"事件上下文"接口（该接口及其数据面板是英文简化版独有的）。接口下线后，英文文章页的可收录判定（决定是否出现在英文站点地图）保持与现在等价：有英文副本且所属事件报道数达到现有门槛才收录。

**Why this priority**: 是版面一致的连带清理，行为上英文文章页从"独有面板"变为"与中文一致"，可见能力不缩水（相关事件结构中文页一直有）。

**Independent Test**: 英文文章页不再请求该接口且功能正常；站点地图的英文收录规则与改造前一致（同样的文章集合）。

**Acceptance Scenarios**:

1. **Given** 改造已上线，**When** 打开任一英文文章页并观察网络请求，**Then** 无对事件上下文接口的请求；页面显示与中文页一致的相关事件结构。
2. **Given** 站点地图生成任务运行，**When** 对比改造前后生成的英文条目集合，**Then** 收录范围等价（有英文副本且事件报道数达门槛的文章）。

### Edge Cases

- 报告的某条引用既无英文摘要、原标题又是中文：英文版面中该条省略（维持现英文版规则），不留中文行。
- 收藏夹里存的是中文标题文章：英文收藏页该条显示回退文案（"打开已收藏的原文报道"），不显示中文标题。
- 更新日志条目标题只有中文：英文页显示"类别 · 日期"回退标题，不显示中文标题；"网站上线"条目在中英两侧都有完整展示。
- 空数据：无日报、无主题、无收藏时，中英两侧空态版面一致、文案各自语言。
- 深色模式与移动端：合并后的英文版面继承中文版全部响应式与主题行为，不单独维护样式。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-01**: 主题列表、主题详情、日报、周报、月报、文章、日报归档、关于、更新日志、条款、隐私、反馈、收藏、Agent 接入页，英文展示必须与中文共用同一版面结构，差异仅限文案语言与"无英文内容时槽位省略"。
- **FR-02**: 每个页面同一时刻只渲染一种语言的文本；英文渲染路径不得输出中文内容文本（UI 铁律，回退占位除外）。
- **FR-03**: 系统 MUST 提供 `/en/weekly`、`/en/weekly/<期号>`、`/en/monthly`、`/en/monthly/<期号>` 固定英文地址，行为与 `/en/daily` 一致（服务端渲染、hreflang、语言切换互跳）。
- **FR-04**: 语言切换按钮在日报/周报/月报及其任意一期页面上必须能中英互跳（含 `/en` 前缀路径的正确拼解）。
- **FR-05**: 英文报告页的内容槽位 MUST 按"最优可得英文"填充：引用条目用其英文摘要（无则原标题，再无则整条省略）；报告级导语/导读只有中文时省略该槽位。
- **FR-06**: 英文文章页的搜索引擎收录判定（noindex/站点地图）必须与改造前等价：有英文副本且所属事件报道数达到既有门槛。
- **FR-07**: 专用事件上下文接口随其唯一消费方退役：接口、数据装配、类型与相关测试一并删除；删除后文章页（中英）无残留调用。
- **FR-08**: 中文页面必须零回归：合并实现后中文版面的 DOM 结构与交互行为与改造前一致（允许的例外仅限把硬编码文案改为等价的双语函数调用）。
- **FR-09**: 反馈页草稿在中英切换间共享（同一浏览器存一份草稿）；退役旧的英文专用草稿键。
- **FR-10**: RSS 与其他公开出口不受影响（feed 保持现有语言与路径）。

### Key Entities *(include if feature involves data)*

- **页面语言（page language）**: 由 `/en/*` 固定地址或读者本地偏好决定；同一组件按它选择文案。本需求不改其判定规则。
- **报道英文副本（per-report English copy）**: 站点对单篇报道已生成的英文标题/摘要/为何重要；英文版面的内容槽位来源，决定槽位显示、回退或省略。
- **英文收录门槛（English indexability）**: 现有"英文副本存在且所属事件报道数 ≥ 门槛"规则；随接口退役迁移归属，规则本身不变。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-01**: 14 个对齐页面（主题列表、主题详情、日报、周报、月报、文章、日报归档、关于、更新日志、条款、隐私、反馈、收藏、Agent 接入）在中英两侧呈现相同种类的版面区块，人工逐页对比无结构性缺失。
- **SC-02**: `/en/weekly`、`/en/weekly/<期号>`、`/en/monthly`、`/en/monthly/<期号>` 四个地址全部可访问并渲染英文版面，语言切换互跳正确。
- **SC-03**: 抽样英文页面正文文本节点汉字检出为 0（回退占位机制除外）。
- **SC-04**: 事件上下文接口及其代码在仓库中完全移除（路由、装配、类型、测试无残留），`/en/items/<id>` 页面正常渲染且不再发起该请求。
- **SC-05**: 英文站点地图收录集合与改造前等价（同一文章判定为收录/不收录）。
- **SC-06**: 中文页面回归对比通过：逐页截图/结构对比与改造前一致。

## Assumptions

- 报告级英文内容（英文导语、英文版面导读）本期内不做生成，英文报告页按"槽位省略"处理；这是数据现状决定的预期差异，在验收记录中如实呈现。
- 工具页（关于、条款等）维持"同地址偏好切换"，不新增 `/en` 固定地址；固定英文地址仅按 User Story 2 扩到周报月报。
- RSS、API、MCP、Agent Markdown 出口不在范围内，仅要求不被破坏。
- 模块（modules/）当前为空；模块提供的页面块在英文版面中照常渲染，其双语责任归模块作者（与站内既有双语模式一致）。
