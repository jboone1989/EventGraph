## 7. P0 链路发现（仅限本样本）

- **A. 采集滞后即"已知时间"语义**：T0 报道发布→收录 26.5h。10-24 的 known 回放为 0 条线索是正确行为；空态文案已提示"不能据此断言没有"。建议读者文档继续强调，非缺陷。
- **B. 归组积压决定线索完整性**：8 篇窗口内报道，2 篇归组（各自成单文故事）、1 篇 roundup、5 篇采样时无归组决定。影响线索被刻意限定在"本 story 当前路线"内，后续报道不可见——这是 PR #134 的有界设计。**不扩边**（扩边=按关键词跨故事拉稿=共现连线风险）；积压消化本身是 P0 运维项。
- **C. 当事国口径隔离**：TASS 等冲突当事方源（hot_signal、tier 标注）不进故事证据链，影响线索因此不继承其框架；保留在库中供对照。
- **D. occurred_at 精度缺口**：fact 的 occurred_at=`10-22T16:00Z`，而原文"当地时间23日"（伊朗 UTC+3:30 ⇒ 10-22T20:30Z–10-23T20:30Z 窗口），存值落在窗口开始前约 4.5 小时；路线站 `timeEffective` 直接展示该值，而 uncertainty 标志只覆盖"缺失"不覆盖"存在但不准"。**记录为数据质量观察，未改库**（只读红线）；是否给抽取提示词加时区锚定属后续独立决定。
- **E. 市场层与商品/能源脱节**：spec §五 P2 想要的能源/运价指标在本站零覆盖；本例的 492 艘滞留、101 艘次护航等只能站外核验。接入与否=新数据源准入问题，按 spec §四另议。
- **F. 政策阶段的官方证据与未核验节点须分开**：宣布（07-13）、生效（07-14T20:00Z）、持续执行（10-05、10-17；10-25 的 update-108 仍有转述）由 JMIC 015-26、CENTCOM/DVIDS、update-108 三份官方文件支持。**10-22 百日节点仅见未直接打开的 Middle East Eye 二手报道**，07-14+100 天=10-22 仅能验证日期自洽，不能把它算作第四份官方执行时点证据。阶段研究无需立即建新 schema。
- **G. 一手文件自带口径与局限声明**：update-108 对 101 艘次 vs ~138 艘/日自带"两个数据源不可直接比较"脚注，对拥堵数自带"AIS 估算、黑暗船舶不计"声明——spec 验收 3（单位/基线/口径）在真实一手文件里就是标准做法，产品接入时应原样携带，不得简化。
- **H. 企业归属尚缺可核证据**：部分受袭船舶 UFN 隐名；§5.1 同时具名 GHANA PROSPERITY 与 MT ASANA，但所核官方文件均未提供船东/运营方。当前"航运→企业"断链来自缺少船舶归属交叉核验，**不能断言官方文件一律隐名或归属天然不可查**；跨库核对需先做数据源准入与许可评估（spec §四）。
- **I. 政策层也有共现陷阱**：八国外长会议与触雷同日前后脚，站内综合稿标题并称两者；但会议应安卡拉倡议、针对更大战争背景，一手稿件无一字把会议归因于触雷——政策层"综合稿并列≠响应"，与新闻层负例同构。

## 9. 结论

1. **现有投影足够承载当前真实证据**：`stories/facts/publications` + `story-route` + `market_snapshots` + PR #134 工作台可以完整呈现"有证据的线索 + 无证据层的诚实空态"，**不需要新表、不需要新 UI 面板、不需要回填**。
2. 产品内五层状态：物流层 1 条站内线索；政策、企业、市场三层对本事件均为"无证据"层——按 spec 停项标准，"证明某层无证据"同样是合格研究结果。站外研究（§4、§5、§6、§8）则进一步表明：政策与航运层有一手文件可核，**但四条相邻链路两条断链（事实→政策、航运→企业）、一条有据（政策→航运）、一条无对象（企业→市场），另有事实→市场直连断链**，三处断链原因各有实据（政策先于 T0、船舶归属未核实、基准滞后），不是研究欠缺。
3. 本切片**代码零增量**：纯文档/证据交付；T0 信源 `rss-cn-chinanews-world` 的 RSS 摘要-only 许可锁定由既有 `tests/china-source-pack.standalone.test.ts` 承担（先于本 PR 存在，非本 PR 新增证据）。曾考虑为验收 9 补中文 e2e 变体，因 spec 仍为草稿（未经批准的 Spec 不得实施代码）而放弃，留待 P1 实现 PR 一并处理；见 [validation.md](./validation.md)。
