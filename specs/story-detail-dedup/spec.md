**v0.1 样本失效**：v0.1 的 OKX-ICE 样本（`story/93a28e20-…`）于 2026-10-31 在 VM13 返回 404，开发数据已轮换；旧页面观察（11 站 / 多板块重复）不得再作验收锚点。§4 诊断启动时须重抓当前真实样本，并另选一例不同领域 Story。

**在新基线下仍待确认的问题**：
1. 重复残留范围待新样本核实：来源索引已由 #158 并入报道时间线，但 `StoryRoutePanel` 逐站与报道时间线仍各自渲染同一批报道的证据摘要，同一 `articleId` 是否仍多处完整出现须实测。
2. 不确定性标记（单一来源/有修订/发生时间 vs 收录时间）仍不在主报告与时间线各条目旁；#229 的 `reportProvenance()` 正补此缺口，是本 spec 第一优先落地项。

**关键待证实判断（不变）**：v0.1 观察到的“11 个 Fact 站点”不能先验断言数据库归组错误——不同公司、不同日期的独立提交可能具有真正不同的事实身份。归组质量是**待证实假说**，必须按 §4 用数据库与原文证据核查，不得从页面观感倒推。

## 2. 产品边界（原文保留自 v0.1）

- **必须保留**：`/hot` 热点榜现有定位、`/story/:publicId` 稳定 URL/SSR/canonical/结构化数据/索引规则，以及 `/items/:id` 独立新闻 SEO。首页绝不因此改版。
- Story 详情首先是**面向普通读者的连续事件档案**，不同于研究者的图谱调试控制台。优先读懂「发生什么、为何重要、真正改变了什么、下一步有什么已确认的信息值得留意」，而非一次性展开所有可用内部组件。
- 所有原文、纠错证据与公开报道保持可访问；**减少重复展示不等于删报道、撤稿或重写历史**。独立的 `/explore?story=` 承担完整时间机器/图谱/按时点证据，不需要第二个工作台。
- 用户批准本 spec 不等于授权自动批量合并 Fact 或调整生产；实施仍逐 PR 评审。

## 3. 信息层级（按 #158 后页面改写，待 Owner 审定）

1. **一眼读懂**：综述 Panel 移动端首位已由 #158 落实并测试锁定，保持；综述说明一次有证据的 What Next，与新闻解释层 5W1H + So What + What Next 衔接，不在各阶段复制同模块。
2. **关键演化节点**：`StoryRoutePanel` 逐站职责 = 展示每站实际新增的变化、发生/收录时间、独立来源数与可核查原文；是否做“同一阅读阶段”的**展示层**聚合，须等 §4 诊断结论决定，不预设压缩目标站数。不同 Fact 可在阅读层归入同一阶段，**不等于**同一次真实发生，也不得写回 Fact 身份。
3. **完整报道证据**：唯一可筛选报道时间线（#158 已合并来源索引）是主要证据入口；须先补齐原文直链与单一来源/修订/时间口径标记（#229 在做），以真实浏览器验证信息可达后，才评估是否折叠任何残留重复区块；不能先删唯一证据路径。
4. **深入研究入口**：`/explore?story=` 深读入口已由 #158 落实；保持 `clock/asOf` 深链保真，不删独立工作台的既有功能。
5. **空证据状态**：无影响资料/市场快照/官方来源时不堆 0 条卡片；不确定性提示放在相关事实/节点附近，不得误导为“没有影响”。
6. 讨论区（#170 giscus）、热度走势与适量上下文可保留，但不应与核心阅读流重复内容。桌面与约 390px 手机同样符合阅读层次。

## 4. 必须先完成的 Fact 归组诊断（原文保留自 v0.1，先查再改）

- 只读核对样本全部 StoryRoute stations 的 `factId`、每站 `articleId`、`occurredAt`/有效时间、原文 URL、报道的实际行为/主体、已有人工归属/合并/更正记录；**记录可复现证据**而不是仅靠标题相似。
- 手工标注 `SAME_OCCURRENCE`（同一次真实发生）、`SAME_STORY`（同一长期事件的不同真实发展）、仅重复媒体表述，以及证据不足。比较已有模型归组决策/候选检索是否存在漏召回、模型分类失误、来源不同所致的重复或故意保守拆分。
- **不提前设定目标节点数**。核查出的真实独立变化可能是 3、4 或更多；必须保留来源独立性和有意义的不同发生/企业立场。
- 核对 `grouping_decisions` 的 verdict、候选事实和相似度、模型判定与人工更正；区分「未召回本该匹配的 Fact」与「已召回但误判 SAME_OCCURRENCE / SAME_STORY」。记录发现而不是从模型标签倒推出真实性。
- 首轮不批量重跑历史、不训练/替换 grouping 模型、不加新模型验证层；如果诊断证实归组错误，再提出现有人工纠正或具体最小算法修复，独立评审且保留重定向与原文追溯。
- 如事实本来就独立但信息上构成相同“阶段”，**允许仅在展示层做编辑级聚合**，不得为美化 UI 改写 Fact 身份。
