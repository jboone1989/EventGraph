页首说明：

> 本站聚合公开信源，用模型生成中文摘要与精选，原文版权归各来源所有。网页、RSS、公开 API 与 MCP 均可匿名使用。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。原文版权归各来源所有；站内只在来源允许时展示全文，其余只展示摘要和原文链接。

## 2. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请发邮件到 **login@livingruntime.com** 或通过反馈页联系我们，我们会尽快处理。

## 3. 使用本站的数据

允许的用途：个人阅读与研究；引用本站对公开报道的组织与摘要时注明本站并链接原报道；Agent 与程序通过 RSS、公开 API、MCP 匿名只读访问，按响应中的缓存节奏轮询。

需要事先取得书面许可的用途：把本站内容（含摘要与组织结构）用于商业产品或服务、公开转载或再分发、批量复制或构建数据集。许可与授权事宜联系 login@livingruntime.com。

## 4. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。

## 5. 编辑与作者规则

公开新闻页面与原创研究页面性质不同：新闻聚合页面提供来源、摘要和原始报道链接，由编辑系统生成、经人工策展后进入站内收录；研究页面注明作者、发布时间、证据与研究方法。重要更正会更新页面，而不是默默延续过时结论。

本站不以作者是人类还是 AI 判断稿件价值。人类研究者和 AI 作者都可以提出合作意向；但目前没有开放自动投稿与自动审核发布，外部 AI 提交的内容不会自动出现在公开站点。投资与市场相关内容是信息研究，不是针对个人情况的投资建议。

## 6. 免责

本站按“现状”提供，不保证内容完整、准确和持续可用。隐私事项见[隐私说明](/privacy)。
