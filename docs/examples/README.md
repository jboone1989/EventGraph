# Example source inputs

These are fictional, minimal inputs for understanding source extraction. They are not live news or production source configurations.

- [`sources/news.json`](sources/news.json) demonstrates a two-item JSON news list with identifiers, summaries, and publication timestamps.
- [`sources/news.html`](sources/news.html) demonstrates a two-item HTML news list with links and `<time>` elements.

Keep examples separate from deployed source definitions.
